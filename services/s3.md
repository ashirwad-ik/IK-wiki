# AWS S3

Blob storage for interview transcripts.

## Usage (BE only)

- `services/external/s3_service.py` wraps the boto3 client.
- Objects are written at the key: `transcripts/{interview_id}/transcript.json`.
- Triggered by the LiveKit `room_finished` webhook (see [`livekit.md`](livekit.md)).

## Env vars (names only)

- `AWS_ACCESS_KEY_ID_1` 🔑 (⚠️ the `_1` suffix is real — see BE gotchas)
- `AWS_SECRET_ACCESS_KEY_1` 🔑
- `AWS_DEFAULT_REGION`
- `S3_BUCKET_NAME`

See [`../env/README.md`](../env/README.md).
