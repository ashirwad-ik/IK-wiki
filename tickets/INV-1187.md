## Contract (locked across the three repos)

- **LiveKit RPC**: method `request_hint`, empty payload, returns `{tier, text, hint_id, question_index}` (JSON string).
- **BE record endpoint**: `POST /api/v1/ai_mock_interview/interview/{id}/hint`, header `X-Internal-Api-Key`, idempotent on `hint_id`, 422 on WALKTHROUGH for Behavioural.
- **BE summary endpoint**: `GET /api/v1/ai_mock_interview/interview/{id}/hints/summary` returns `{hints_used, by_tier, by_question, penalties}`.
- **Table**: `ai_mock_interview_hints (id, interview_id, question_index, tier VARCHAR(20), hint_id VARCHAR(64) UNIQUE, text TEXT, created_at)`.
