## Scope

Tab close / refresh / Ctrl+W shows the native "Leave site?" prompt and nothing else. Cancel resumes the interview with the agent still connected; real leave persists `aimi-abandoned` and PATCHes `ABORTED` via `keepalive`.

- `src/hooks/useTerminateOnUnload.ts` — `beforeunload` sets `returnValue`; `pagehide` guarded on `event.persisted` (bfcache) PATCHes `ABORTED` with `keepalive: true`.
- `popstate` swallowed so Back cannot drop the interview silently.
- LiveKit room: `disconnectOnPageLeave: false` → agent stays connected across the native prompt.
- No in-app card on this path (reversed from the 2026-11-13 plan).
