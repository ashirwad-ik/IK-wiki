## What it does

Adds a short-path alias `GET /interview/{interview_id}/feedback-status`. Identity comes from the auth cookie, and the user segment is ignored. The FE uses it to gate the report page (INV-1156). It is harmless in prod. See [`../integrations/fe-be-contract.md`](../integrations/fe-be-contract.md).
