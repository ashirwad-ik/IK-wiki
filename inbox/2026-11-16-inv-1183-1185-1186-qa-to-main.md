# 2026-11-16 — INV-1183 / 1185 / 1186: three exit surfaces separated, qa → main PR raised

**Repo:** `ai-mock-interview-fe-v2`
**PR:** [#22 qa → main](https://github.com/ikickstart/ai-mock-interview-fe-v2/pull/22) — "Release: INV-1183, INV-1185, INV-1186"
**Tickets:** INV-1183 (tab-close), INV-1185 (focus-leave card), INV-1186 (end-click card; also subsumes INV-1184).

## What changed vs the 2026-11-13 state

The architecture shifted. The old plan (card on Cancel of the native prompt, queued via `setTimeout` inside `beforeunload`, cleared by `pagehide`) is **gone**. The three exit paths now have one surface each, and they don't stack.

| Trigger | Surface | Hook / change |
|---|---|---|
| Tab close / refresh / Ctrl+W | Native "Leave site?" prompt only | `useTerminateOnUnload` (unchanged) |
| Tab switch / window-blur / cursor-to-tab-bar | In-app "Before you go" card, **once per interview** | new `useFocusLeaveOnce` |
| In-room End button below 25% elapsed | End-click confirmation card | INV-1186 card |

## Key new/changed files

- **`src/hooks/useFocusLeaveOnce.ts`** (new) — fires `onLeave` at most once per mount on `visibilitychange → hidden` or `document.mouseleave` (clientY ≤ 0, debounced 450 ms). `beforeunload` + `mouseenter` cancel the pending mouseleave trigger. **`window.blur` is deliberately NOT listened to** — Chrome also fires blur when it opens the native prompt, which caused the card to appear after Cancel (the whole reason this ticket re-opened).
- **LiveKit room** — `<LiveKitRoom options={{ disconnectOnPageLeave: false }}>`. Keeps the agent connected across the native "Leave site?" prompt so Cancel resumes the interview mid-sentence. Side benefit: skips the mic-after-Cancel recovery hop entirely for the native-prompt path (room never torn down, nothing to restart).
- **`useTerminateOnUnload.ts`** — no more card-queue plumbing. Just the native prompt (`beforeunload` sets `returnValue`), and `pagehide` (bfcache-guarded via `event.persisted`) persists `aimi-abandoned` + PATCHes `ABORTED` with `keepalive`. `popstate` still swallowed.
- **End-click card** (INV-1186) — `sm:max-w-3xl`, full-width orange countdown + 2-col body (*What you'll miss* | *How to get there*). Non-blocking mic restart on Keep interviewing. Keyboard shortcuts suppressed while open.

## Decisions / gotchas

- **Debounce window is 450 ms.** Chosen so `beforeunload` lands (if the user is heading to close the tab) within the window and cancels the card. Shorter misses the race; longer makes legitimate tab-switches feel laggy.
- **Cancel shows NO in-app card.** This is intentional and a reversal of the 2026-11-13 plan. The previous "card after Cancel" behaviour was unlovable and unreliable (triggered on blur, triggered on mouseleave headed to the ✕).
- **`window.blur` must stay un-listened-to** in `useFocusLeaveOnce`. Documented in the hook's JSDoc; if a future change re-adds it, the Cancel-shows-card regression comes back.
- **Mic cascade status (BE/worker side):** unchanged. The 2026-11-13 BE `empty_timeout` + webhook-guard + worker grace-period work is still unshipped, still waiting on manager alignment. With `disconnectOnPageLeave: false`, the FE no longer contributes to the cascade on the native-prompt path (room stays up), but the broader LiveKit disconnect → empty_timeout → room_finished → ABORTED path still exists for genuine disconnects.
- **INV-1184** is a duplicate of INV-1186 and should be closed as such. End-click-below-25% is owned by INV-1186; tab-close by INV-1185.
