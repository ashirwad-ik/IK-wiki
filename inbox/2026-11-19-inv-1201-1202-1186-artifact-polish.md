## INV-1202 — report page / no-report loader fixed **at the API source**

- **Root cause of the "infinite" loader on aborted / short sessions:** `useGetReportByIdApi` polled every 10 s for up to 4 min while backend returned `report_status === 'PENDING'`, and only exited on `FAILED` — `NOT_STARTED` kept it looping.
- **Fix at the hook, not the page.** Treat any non-`PENDING` as terminal; throw on `FAILED` **and** `NOT_STARTED`. React-query surfaces `isError: true`, `hasReport = false`, page falls through to `<NoAnalysis>` immediately. One honest call, no 4-min wait, no reliance on history cache being warm (works on reload and deep links).
- Earlier history-cache short-circuit (commit `5a40c72`) was reverted — API response is the single source of truth now, simpler.
- **`NoAnalysis` copy reverted to the PM-approved original** ("No report for this session" / "ended too quickly"). Dropped the three-bucket `reason` / `endReason` branching I'd added — was off-brief.
- Blur gate still right: `isGateShown = showFeedbackGate` only; `ReportGenerating` stays fully opaque while it's up; report + blur + feedback card still mount in the same commit. No flash of unblurred scores on initial load / refresh / cached reload.
